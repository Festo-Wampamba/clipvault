# Code of Conduct

ClipVault adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, be respectful, accept constructive feedback gracefully, and focus on what is best
for the community. Harassment, insults, personal or political attacks, and publishing others' private
information are not acceptable in any project space — issues, pull requests, discussions, or chat.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainers using
GitHub's **Report content** option on the comment, issue, or pull request in question. All reports are
reviewed promptly and kept confidential.

## Enforcement

Maintainers follow the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, or permanent ban, depending on severity.
